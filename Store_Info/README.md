# Store_Info/ — всё для публикации в магазине

В этой папке лежат файлы, **связанные с публикацией приложения в РуСтор** (и потенциально другие сторы): иконки, скриншоты, описание, политика конфиденциальности, ключ подписи APK.

**Никакая** часть этой папки (кроме `icon.png`) не попадает в собранный APK — это **метаданные для магазина** и для тебя как разработчика. Игровые ассеты (картинки, звуки, музыка) клади в `public/` (Vite) — они попадут в `dist/` и в APK.

## Содержимое

| Файл / папка | Размер / тип | Куда уходит |
|--------------|--------------|-------------|
| `keystore/release.jks` | бинарь | **В APK** (как подпись) — html2apk auto-detect при `-Release`. См. `keystore/README.md`. |
| `keystore/keystore.config.json` | alias + пароли | Читается html2apk. |
| `icon.png` | 1024×1024 PNG | **В APK** — html2apk через `iconPath` в `.claude/build-config.json` уменьшает в `mipmap-*`. |
| `store-icon.png` | 512×512 PNG | **В магазин** — RuStore Console, страница приложения. Вручную. |
| `store-feature.png` | 1024×500 PNG | **В магазин** — баннер (опционально). |
| `screenshots/01..NN.png` | 1080×1920 PNG | **В магазин** — скриншоты. Минимум 4, рекомендуется 6-8. |
| `STORE_LISTING.md` | markdown | Тексты для страницы магазина. Копируется руками в RuStore Console. |
| `PRIVACY_POLICY.md` | markdown | Источник правды текста политики. Редактируй здесь. |
| `PRIVACY_POLICY.pdf` | PDF | Готовый файл для облака. Регенерируется из .md (Claude умеет). Появится перед первым релизом. |

## Сейчас здесь заглушки

PNG-файлы — тёмные с надписями размера/назначения. **Замени** на реальные арты до публикации. Не переименовывай `icon.png` / `release.jks` — html2apk ищет их по этим именам. Не меняй размеры PNG — РуСтор отвергает нестандартные dimensions. Не удаляй `release.jks` — потеряешь подпись и не сможешь обновлять опубликованные приложения.

## Статус MVP

Реклама (Yandex Mobile Ads) и RuStore Review SDK **в MVP не подключены** — см. `docs/ADS.md`. Поэтому текущая `PRIVACY_POLICY.md` декларирует, что данные не собираются. При интеграции рекламы политику и `build-config.json` (`rustoreReviewSdk`) нужно обновить.
