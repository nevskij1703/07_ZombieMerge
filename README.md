# ZombieMerge (рабочее название)

Merge-игра на HTML для Android (РуСтор). На базе (вид сверху, портрет) внизу — мердж-поле,
по центру забор, сверху — заражённый зомби город. Мастерская из металлолома (софт-валюта)
штампует оружие; мерджем поднимаем тир. Когда лом кончается — отправляем Бойцов (число = ширина
поля) в авто-бой по линиям: они добегают до сундуков или отступают, когда выходит ресурс оружия.
Беспроигрышно. Чертежи из сундуков апгрейдят тир производства Мастерской.

## Стек

- **Phaser 3** + **TypeScript** + **Vite**.
- Сборка в APK — через html2apk (пакует `dist/`).

## Запуск (dev)

```bash
npm install
npm run dev      # http://localhost:8777
```

Превью-окно Claude Code читает `.claude/launch.json` (порт **8777**, `strictPort`).

## Сборка

```bash
npm run build    # → dist/  (base:'./' — относительные пути для WebView/APK)
npm run preview  # локальный предпросмотр прод-сборки
```

## Дев-панель и чит-код

Дев-панель (правка ресурсов, скип уровней, сброс сейва, редактор баланса с export/apply JSON)
живёт **только в dev** — гейтится `import.meta.env.DEV`, Vite вырезает её из прод-сборки
(release APK чистый автоматически). Подробности — в `CLAUDE.md`.
