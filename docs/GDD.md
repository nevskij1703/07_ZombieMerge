# ZombieMerge — Game Design (краткий GDD)

Рабочее название. Жанр: merge + авто-бой по линиям + idle-прогрессия. Платформа: Android (РуСтор), портрет. Сессия: ~1 мин мердж + ~1 мин бой = ~2 мин на цикл.

## Главный экран (база, вид сверху)

Сверху вниз: **заражённый город** (зона боя) → **забор + ворота** → **база** (низ экрана). На базе:
- **Мердж-поле** — грид. Стартует 2×2, растёт по уровням до 5×5 (бывает неквадратным: 2×3, 3×4, …). Ширина (cols) = число линий и Бойцов в бою.
- **Мастерская** — за металлолом штампует оружие текущего производимого тира (старт — тир 1, Труба). Цена растёт с тиром.
- **HUD** — металлолом, текущий уровень, тир Мастерской; кнопка **«В бой»**.
- **Инвентарь переполнения** — буфер для лута, не влезшего на поле; вынос на поле бесплатный при наличии слота.

## Кор-петля

1. **Производство**: тратишь металлолом → Мастерская кладёт на поле оружие текущего тира.
2. **Мердж**: два одинаковых оружия → одно следующего тира. Глубина MVP — 12 тиров (позже 50-100).
3. **Отправка в бой**: когда металлолом кончается (или по желанию) — жмёшь «В бой». Кол-во Бойцов = ширина поля. Каждый Боец берёт **всё** оружие своего столбца.
4. **Бой** (игрок наблюдает, не управляет): см. ниже.
5. **Возврат**: оружие восстанавливается на исходных клетках; новый лут раскладывается по свободным клеткам (переполнение → инвентарь). Петля замыкается.

## Оружие (12 тиров, MVP)

Труба → Лом → Топор → Нож → Катана → Пистолет → Узи → Автомат → Пулемёт → Гранатомёт → Огнемёт → Рейлган. *(имена/числа — в `src/config/balance.ts`, переименуемо; позже добавим промежуточные тиры)*

Каждый тир: больше урона и больше «ресурса» (выносливость/боезапас) — параметры **скрыты** от игрока. Мердж бесплатный; платный — только спавн из Мастерской.

## Бой (авто, по линиям)

- Каждый Боец бежит по своей линии (параллельно столбцам поля). Зомби **стоят неподвижно** — это препятствия на линии.
- **Модель оружия (зафиксировано):** боец бьёт **сильнейшим** оружием столбца; когда его ресурс кончился — переходит к следующему по силе; всё израсходовано → **разворот на базу**.
- На дороге: **металлолом** (подбирается свободно), **ящики** (HP, надо разбить — тратит ресурс — выпадает лут: оружие/металлолом).
- В конце линии — **сундук** (по одному на линию). Боец, добежавший до конца, открывает свой сундук, не дожидаясь других, и возвращается.
- **Нельзя умереть. Оружие не теряется.** Если ресурс кончился — просто возврат.
- **Уровень пройден**, если до сундука дошёл **≥1** Боец. Иначе уровень не зачтён и будет повторён при следующей отправке.
- Беспроигрышно: с каждого рейда игрок уносит как минимум металлолом → апгрейдит арсенал → рано или поздно дожимает уровень. Сложные уровни = точки монетизации (после MVP).

## Зомби (MVP — 3 типа)

Слабый / Средний / Сильный — отличаются HP. Состав по уровням: ранние — только слабые; средние — слабые, ближе к концу средние; поздние — слабые → средние → сильные. Плотность/состав регулируются балансом.

## Сундуки и Чертежи

Сундук содержит (рандом по балансу): **металлолом**, **оружие**, **Чертёж**. Чертёж → **апгрейд Мастерской**: она начинает производить следующий тир (и дороже). Это поднимает «дно» поля, разгружает грид и ускоряет поздний мердж.

## Уровни

Каждый бой = уровень. Всего MVP — **50** автогенерируемых уровней. С ростом: больше/сильнее зомби, длиннее дорога. Генерация **детерминирована** от номера уровня + баланса (воспроизводимо, легко тюнить). Размер поля растёт по порогам уровней.

## Экономика / валюты

- **Металлолом** (софт) — основной ресурс: спавн оружия, дропы из боя/сундуков. Полный цикл в MVP.
- **Алмазы** (хард) — прокачка Бойцов и пр. **Отложено вместе с метой**; в сейве зарезервировано поле.

## Дев-панель (обязательна, только в dev)

Гейтится `import.meta.env.DEV` (Vite вырезает из релиза). Вкладки:
- **Ресурсы**: задать металлолом/алмазы, тир Мастерской.
- **Прогресс**: выбрать/скипнуть уровень, сбросить сейв.
- **Баланс**: live-редактирование `balance.ts`, «Скопировать JSON» (отдать Claude для вставки новых значений) и «Применить». См. `docs/BALANCE.md`.

## MVP scope

**В MVP:** кор-петля целиком на примитивах (мердж, Мастерская, бой по линиям, сундуки, чертежи→тир, 50 уровней, рост поля, инвентарь, металлолом, сейв+миграции, дев-панель). Утилитарный UX, без финального арта.

**Не в MVP:** именные Бойцы/лор/карточки/прокачка, алмазные синки, магазин, сюжет, новые локации, бустеры, боссы, усталость Бойцов, async-PvP, альт-режимы, продажа лутбоксов, косметика, расширенные типы зомби, ивенты/баттл-пас/дейли, сервер/лаунчер-WebView, Spine-анимации, звук.

**Никогда:** синхронный мультиплеер, броня Бойцов, переход на Unity/Unreal.
