# Баланс (ZombieMerge)

Единый источник правды — **`src/config/balance.ts`** (типизированный объект `Balance`). Всё, что влияет на экономику/сложность, живёт здесь, а не разбросано по коду. Цель — крутить числа без правки логики.

## Что описывает `balance.ts`

- **weapons[1..12]**: `{ name, damagePerHit, hits }`. `hits` — сколько ударов до истощения оружия (выше тир → больше урон **и** больше ударов = «меньше расход»). Урон/ресурс **скрыты** от игрока.
- **workshop**: `produceCostByTier[tier]` — цена спавна в металлоломе (растёт с тиром); `startTier = 1`; чертёж даёт `+1` к производимому тиру.
- **field**: прогрессия размеров по порогам уровней, напр. `[{fromLevel:1, cols:2, rows:2}, {fromLevel:3, cols:2, rows:3}, …, {fromLevel:N, cols:5, rows:5}]`. `cols` = число линий/Бойцов.
- **zombies**: `{ weak:{hp}, medium:{hp}, strong:{hp} }`.
- **levelGen**: по номеру уровня → длина дороги, плотность и состав зомби (band'ы: до уровня k только weak; дальше + medium ближе к концу; поздние + strong), число/HP ящиков, металлолом на дороге, содержимое сундука (металлолом; шанс и тир оружия; шанс чертежа).
- **economy**: базовые дропы, шансы, стартовые ресурсы.

Генерация уровня **детерминирована** (seed = номер уровня) — один и тот же уровень всегда одинаков, удобно тюнить.

## Поток правок баланса (дев-панель ↔ Claude)

Дев-панель (вкладка **Баланс**, только в dev) умеет:
1. **Live-edit** — менять числа на лету, изменения кладутся в `localStorage['zm_balance_override']` и сливаются поверх `balance.ts` в рантайме (`src/core/balanceRuntime.ts`). Перезагрузка сохраняет override.
2. **Скопировать JSON** — весь текущий (слитый) баланс в буфер обмена.
3. **Применить JSON** — вставить отредактированный JSON и применить.
4. **Сбросить override** — вернуться к значениям из `balance.ts`.

**Рабочий цикл с Claude:** покрутил числа в дев-панели → «Скопировать JSON» → прислал JSON в чат → Claude вставляет новые значения в `balance.ts` (это становится новым дефолтом для всех) → можно «Сбросить override».

> Override в отдельном ключе и **не влияет** на схему сейва (миграции его не трогают). В release-сборке вкладка Баланс и override-механизм вырезаются (`import.meta.env.DEV`).

## Принципы

- Меняем **числа в balance.ts**, не логику в core/*.
- Беспроигрышность — инвариант: даже на проваленном уровне игрок уносит ≥ немного металлолома.
- Целевой ритм: ~1 мин мердж + ~1 мин бой.
