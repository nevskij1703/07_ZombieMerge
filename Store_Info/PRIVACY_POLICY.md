# Политика конфиденциальности приложения «ZombieMerge»

Эта страница описывает, какие данные собираются при использовании мобильного приложения «ZombieMerge» (далее — «Приложение») и как они обрабатываются.

> **Статус MVP:** на текущем этапе реклама и сторонние SDK сбора данных **не подключены**. Приложение не собирает персональных данных. Раздел про Yandex Mobile Ads ниже — заготовка: его нужно активировать (и обновить версию политики) при интеграции рекламы.

## Кто разработчик

Приложение разработано индивидуальным разработчиком (далее — «Разработчик»). Связь: terekh-spb@mail.ru.

## Какие данные собирает само Приложение

**Никаких персональных данных Приложение не собирает и не передаёт.**

Внутри устройства Приложение хранит только локальный игровой прогресс (`localStorage` WebView): текущий уровень, состояние мердж-поля и инвентаря, тир Мастерской, количество ресурсов, настройки. Эти данные:

- хранятся **только на устройстве пользователя**;
- не передаются ни Разработчику, ни третьим лицам;
- удаляются при удалении приложения;
- могут быть очищены через системные настройки приложения.

## Какие данные собирают встроенные сервисы

На текущем этапе — **никакие** (сторонние SDK не подключены).

## Возрастные ограничения

Приложение предназначено для лиц от 12 лет (категория 12+). При подключении рекламы SDK может ограничивать тип показываемой рекламы для несовершеннолетних согласно законодательству РФ.

## Права пользователя

Пользователь имеет право:

- **Удалить локальные данные**: настройки Android → Приложения → «ZombieMerge» → Хранилище → «Очистить данные», либо удалить приложение.
- **Связаться с Разработчиком** по любым вопросам: terekh-spb@mail.ru.
- *(После подключения рекламы)* **Отключить персонализированную рекламу**: настройки Android → Реклама → «Сброс рекламного идентификатора».

## Cookies, аналитика, серверный обмен

Приложение **не использует**: cookies, сервисы аналитики (Google Analytics, AppMetrica, Firebase), собственный backend/API, авторизацию, push-уведомления, геолокацию.

## Изменения политики

Разработчик может обновить эту политику. Существенные изменения будут сопровождаться повышением версии приложения и публикацией новой версии этого файла в облаке (URL остаётся прежним).

## Контакты

По вопросам обработки данных, удаления или жалобам: terekh-spb@mail.ru.

## Как захостить эту политику (для разработчика)

РуСтор требует публичный URL политики при наличии рекламы/сбора данных. Самый простой способ — облако:

1. Перед релизом сгенерируй `PRIVACY_POLICY.pdf` из этого `.md` (Claude умеет; делает skill `prepare-release-candidate`).
2. Загрузи `PRIVACY_POLICY.pdf` на облако:
   - **Cloud Mail.ru** (cloud.mail.ru) — почта `terekh-spb@mail.ru` привязана. Публичная ссылка **не меняется** при перезаливе файла с тем же именем — удобно для апдейтов.
   - Yandex Disk / Google Drive — альтернативы.
3. Создай публичную ссылку («по ссылке кому угодно»), скопируй URL.
4. Впиши URL в **двух местах**: `STORE_LISTING.md` → privacyUrl **и** в код (`PRIVACY_URL` константа). Адреса должны совпадать.
